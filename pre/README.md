# 简单 HTML 弹幕射击游戏（STG）

这是一个使用原生 **HTML + CSS + JavaScript** 编写的单文件弹幕射击小游戏，主文件为 `index.html`。

## 目录结构

```text
pre/
├── index.html   # 游戏主文件
└── README.md    # 运行说明
```

## 运行方式

### 方式一：直接打开

在文件管理器中直接双击 `index.html`，使用浏览器打开即可运行。

### 方式二：使用本地静态服务器（推荐）

在 `pre/` 目录下启动一个简单 HTTP 服务：

```bash
cd pre
python3 -m http.server 8000
```

然后在浏览器中访问：

```text
http://localhost:8000
```

## 游戏操作

- `← / A`：向左移动
- `→ / D`：向右移动
- `↑ / W`：向上移动
- `↓ / S`：向下移动
- `空格`：射击
- `R`：游戏结束后重新开始

## 游戏说明

- 玩家控制自机移动并发射子弹。
- 敌机会从上方出现，并向玩家发射弹幕。
- 玩家子弹击中敌机会得分。
- 被敌机或敌方子弹击中后游戏结束。
- 游戏结束后可按 `R` 键重新开始。

## 兼容性说明

建议使用现代浏览器运行，例如：

- Chrome
- Edge
- Firefox

## 备注

如果浏览器直接打开本地文件时出现限制，建议使用上面的本地静态服务器方式启动。
